# Phase Diagrams

The supervisor logic drives several phases from clarification to execution. The state diagram below summarizes the lifecycle of a global plan.

## Global Plan State Machine
```mermaid
stateDiagram-v2
    [*] --> INITIAL_OBJECTIVE_RECEIVED
    INITIAL_OBJECTIVE_RECEIVED --> OBJECTIVE_BEING_CLARIFIED_BY_AGENT
    OBJECTIVE_BEING_CLARIFIED_BY_AGENT --> CLARIFICATION_PENDING_USER_INPUT
    CLARIFICATION_PENDING_USER_INPUT --> OBJECTIVE_BEING_CLARIFIED_BY_AGENT
    OBJECTIVE_BEING_CLARIFIED_BY_AGENT --> OBJECTIVE_CLARIFIED
    OBJECTIVE_CLARIFIED --> TEAM1_PLANNING_INITIATED
    TEAM1_PLANNING_INITIATED --> TEAM1_PLANNING_COMPLETED
    TEAM1_PLANNING_INITIATED --> TEAM1_PLANNING_FAILED
    TEAM1_PLANNING_COMPLETED --> TEAM2_EXECUTION_INITIATING
    TEAM2_EXECUTION_INITIATING --> TEAM2_EXECUTION_IN_PROGRESS
    TEAM2_EXECUTION_IN_PROGRESS --> TEAM2_EXECUTION_COMPLETED
    TEAM2_EXECUTION_IN_PROGRESS --> TEAM2_EXECUTION_FAILED
    TEAM1_PLANNING_FAILED --> [*]
    TEAM2_EXECUTION_FAILED --> [*]
    TEAM2_EXECUTION_COMPLETED --> [*]
```
